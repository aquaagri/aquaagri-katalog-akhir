Jika dinonaktifkan, ikon lonceng melayang dan banner penawaran diskon VIP akan disembunyikan sepenuhnya dari website pengunjung.

Pengaturan Kunci API OneSignal (Opsional / Siap Pakai)
💡 3 Langkah Mudah Agar Notifikasi Terkirim ke HP Lain:
  1. REST API Key: Masukkan kunci rahasia yang berawalan os_v2_app_... (bukan nama label kuncinya).
  2. Aktifkan Web Push di onesignal.com: Buka Settings → Platforms → Web, pilih Typical Site, masukkan URL https://aquaagri-katalog-akhir.aquaagri-id.workers.dev, lalu Simpan.
  3. Daftarkan HP: Buka website katalog dari HP lain dan ketuk tombol Aktifkan Diskon VIP pada ikon lonceng agar nomor perangkat HP tersebut terdaftar (Subscribers > 0).
✨ Formula Copywriting S3 Marketing (Pilih 1-Klik untuk Mengisi Formulir)

Klik salah satu formula psikologis di bawah untuk langsung menyusun judul & pesan dengan daya pikat tinggi:

Disarankan maks 45-50 karakter agar terbaca penuh di layar HP. 0/65
Buat pesan to-the-point yang memicu rasa penasaran untuk segera diklik. 0/120
Pengunjung yang mengetuk notifikasi di HP-nya akan langsung diarahkan ke tautan ini (Aktifkan cookie 7 hari!).
